# Sons et musique

Dépose ici tes propres sons (format .ogg ou .wav). Ils remplacent automatiquement les
sons synthétisés par `scripts/sfx.gd` :

| Fichier | Moment |
|---|---|
| `swing.ogg` | coup d'épée |
| `hit.ogg` | impact sur un ennemi |
| `lightning.ogg` | 5e coup (éclair) |
| `jump.ogg` | saut |
| `levelup.ogg` | montée de niveau |
| `fly.ogg` | décollage (vol) |
| `divine.ogg` | Transformation Divine |
| `hurt.ogg` | le héros est touché |
| `enemy_die.ogg` | mort d'un ennemi |
| `musique.ogg` | musique de fond (en boucle) |

Utilise uniquement des sons libres de droits (CC0) ou créés par toi.
